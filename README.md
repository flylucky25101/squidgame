# LAST CITY · 목숨의 가격

해문시에서 차량을 탈취하고, 동맹을 맺고, 데스 게임을 통과해 조직을 성장시키는 **3D 브라우저 생존 액션 프로토타입**입니다.

## 현재 플레이할 수 있는 것

- 건물과 충돌하는 3D 도시 탐험, 카메라 회전·줌, 전체 지도·미니맵
- 12대의 차량 탈취, 가속·제동·후진·조향, 부스트와 차량 내구도
- 권총 조준·사격·재장전, 탄약과 의료품, 집행국의 추적
- 경쟁 NPC 12명, 집행국 6명, 협력자 윤서
- 윤서와의 동맹, 전투 지원·전력 복구 시 치료, 공동 배당과 배신
- **연대채무 → 도시의 심장 → 마지막 배당**의 연속 대회
- 적색 신호의 행동 제한과 예고되는 VIP 정전
- 우승 상금, 정비소·진료소·정보망 구매, 세력 선택과 영향력
- 참가자의 영구 퇴장과 조직 자산·기록의 브라우저 자동 저장
- 일시정지, 소리·화면 흔들림·저사양 설정, 기본 터치 조작

## 실행

Node.js 22.13 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. WebGL2와 하드웨어 가속을 지원하는 데스크톱 브라우저를 권장합니다.

```sh
pnpm test       # 게임 규칙 회귀 테스트
pnpm typecheck  # TypeScript 검사
pnpm build     # 배포 빌드
pnpm start     # 생성된 Worker의 로컬 실행
```

패키지 설치 스크립트의 허용 여부는 `pnpm-workspace.yaml`에 명시되어 있습니다. 사전 빌드된 플랫폼 패키지를 사용합니다.

## 조작

| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 / 차량 가속·제동·조향 |
| Shift | 질주 / 차량 부스트 |
| 마우스 / 왼쪽 버튼 | 조준 / 도보 사격 |
| 오른쪽 버튼 드래그 / 휠 | 카메라 회전 / 거리 조절 |
| E | 보관함, 등록소, 상환소, 변전소, 탈출, NPC 상호작용 |
| F | 차량 탈취 / 저속 상태에서 하차 |
| R / H | 재장전 / 응급 처치 |
| M / Tab / Esc | 전체 지도 / 조직 관리 / 일시정지 |

## 대회

1. **연대채무 · 210초:** 보관함에서 증서 100을 모아 중앙 상환소에 납부합니다. 녹색 25초, 황색 3초, 적색 7초가 반복됩니다. 적색 중 추진·조향·발포는 25 피해를 주며 2초의 재판정 간격이 있습니다. 제동과 관성 이동은 허용됩니다.
2. **도시의 심장 · 210초:** 서로 다른 변전소 3곳을 복구합니다. 정전은 미리 고지됩니다. 살아 있는 동맹이 있으면 복구 때 체력을 회복합니다.
3. **마지막 배당 · 150초:** 북동쪽 항만의 회수 차량에 도착해 E로 탈출합니다. 단독 배당은 20,000 C, 살아 있는 동맹과의 공동 배당은 10,000 C입니다.

도시에서는 밀수품으로 자금을 얻고 은신처에서 회복할 수 있습니다. 일반 도시의 패배는 응급 구조비를 차감하고, 대회의 패배는 참가자를 영구 퇴장시킵니다. 기존 조직의 자금과 시설은 유지됩니다.

## 저장

조직 정보는 이 브라우저의 `localStorage`에 저장됩니다. 서버 계정 저장·기기 간 동기화는 없습니다. 진행 중인 대회는 새로고침하면 종료됩니다. 브라우저 데이터를 삭제하면 조직 저장도 사라집니다.

## 구조

```text
app/game/model.js       게임 상태, 규칙, 경제, 충돌, NPC 로직
app/game/engine.js      Three.js 도시·캐릭터·차량, 입력, 카메라, 효과음
app/game/LastCity.tsx   시작 화면, HUD, 지도, 설정, 조직 관리
app/globals.css         전체 인터페이스와 반응형 레이아웃
tests/model.test.mjs    진행·정산·사망·차량·저장·전투 회귀 테스트
```

기술: React 19, Three.js, TypeScript, Vite/Vinext, Tailwind CSS, Base UI/Shadcn. 도시는 코드로 생성하며 외부 이미지나 유료 API는 필요하지 않습니다.

## 구현 범위

이 저장소는 기획의 핵심 순환을 플레이할 수 있도록 만든 싱글플레이 수직 슬라이스입니다. AAA 완성작이나 온라인 멀티플레이 서비스는 아닙니다. 실제 플레이어 매칭, 권위 서버, 공동 거래 원장, 시즌 영토전, 거대한 연속 도시, 완전한 NPC 사회·경쟁 시뮬레이션은 아직 구현되지 않았습니다.

원래 기획의 50~70분 대회는 이 버전에서 최대 9분 30초로 축약했습니다. NPC 수, 장비, 부동산과 세력 시스템도 구현 범위에 맞게 축소했습니다. 저장 데이터는 로컬 게임용으로 신뢰되며 온라인 경쟁이나 현금 거래에 사용할 수 없습니다.

## 검증

게임 모델 회귀 테스트와 TypeScript 검사, 프로덕션 빌드를 수행합니다. 브라우저별 그래픽 품질과 실제 플레이 체감에 대한 수동 QA는 별도 검증이 필요합니다.

## 배포

`.openai/hosting.json`은 소유자의 Sites 배포 프로젝트를 가리킵니다. 다른 계정에 복제한 뒤에는 자신의 배포 대상에 맞게 설정해야 합니다. 인증 토큰과 비밀 키는 저장소에 포함하지 않습니다.
